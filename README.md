# Airbnb Backend Clone

A simple Airbnb-inspired backend project built for learning Node.js, Express.js, and MongoDB.  
This project focuses on backend development concepts like routing, database handling, CRUD operations, and server-side architecture without implementing authentication or authorization.

## Features

- Add new homes/listings
- View all listed homes
- View individual home details
- Edit home information
- Delete home listings
- MongoDB database integration
- RESTful routing structure
- Express.js server setup
- MVC-style project organization

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS / HTML
- CSS
- JavaScript

## Learning Objectives

This project was created to practice:

- Backend development with Node.js
- Express.js routing
- MongoDB database operations
- Mongoose schema modeling
- CRUD functionality
- Server-side rendering
- Form handling
- Database connectivity
- MVC project structure
